## US-01 · Rank latest shortfalls

As an ED lead, I want to rank the four latest measures by target minus actual so that I can choose the first review.

Parent: FR-01 · Priority: Must · Delivered.

AC-01.1 — Given the four latest results, when I open the service review, then ED stay leads at 25.2 percentage points.

## US-02 · Count standards achieved

As an ED lead, I want to count each latest measure once when actual meets or exceeds target so that I can identify which standard met target.

Parent: FR-02 · Priority: Must · Delivered.

AC-02.1 — Given four monitored standards, when I count the standards that met target, then one of four meets target: category 1 immediate treatment.

## US-03 · Compare annual movement

As an ambulance liaison, I want to see three years of handover and ED stay results together so that I can distinguish transfer performance from total stay.

Parent: FR-03 · Priority: Must · Delivered.

AC-03.1 — Given three published results per series, when handover and ED stay are compared, then handover rises 5.9 points and the share under four hours falls 4.2 points across the period.

## US-04 · Explain the longer-stay share

As an ED lead, I want to show the share of visits lasting four hours or longer in each year so that I can scope a local review.

Parent: FR-04 · Priority: Must · Delivered.

AC-04.1 — Given 49.8% under four hours, when the 2025–26 stay split is displayed, then 50.2% lasted four hours or longer.

## US-05 · Trace evidence

As a performance analyst, I want to link each register row to its publication so that I can reproduce the comparison.

Parent: FR-05 · Priority: Must · Delivered.

AC-05.1 — Given eight measure–year records, when the register is downloaded, then each pair is unique and has a source URL.

## US-06 · Read results offline

As a portfolio reader, I want to display all four views with network access disabled so that I can review evidence offline.

Parent: NFR-01 · Priority: Must · Delivered.

AC-06.1 — Given a downloaded dashboard, when the reader switches views offline, then each view displays its local data.
